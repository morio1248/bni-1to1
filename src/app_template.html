1to1シートを取り込む

Googleの無料AI「Gemini」がシートを読み取り、各項目に振り分けます。手入力はほとんど要りません。

1
シートの届き方を選ぶ
  1. 「ページを開く」で別タブにシートが開きます
  2. 開いたページで Ctrl＋A（全選択）→ Ctrl＋C（コピー）Macは ⌘　※スマホは長押し→「すべて選択」→「コピー」
  3. このタブに戻り、下の枠をクリックして Ctrl＋V（貼り付け）

シートのファイルは、手順2でGeminiに添付します。先にパソコン（スマホ）に保存しておいてください。

2
Geminiに読み取ってもらう
  1. 「指示文をコピー」を押す（貼り付けたページの内容も一緒にコピーされます）
  2. 「Geminiを開く」→ 入力欄をクリックして Ctrl＋V → 送信
  1. 「指示文をコピー」を押す
  2. 「Geminiを開く」→ 入力欄をクリックして Ctrl＋V
  3. 入力欄の左の 「＋」→「ファイルをアップロード」でシートのファイルを選び、送信
    添付できない形式のときは、PDFで保存し直してから添付してください。
3
Geminiの返答を貼り付ける

返答の下にあるコピーのアイコン（四角が2つ重なった形）を押し、下の枠をクリックして Ctrl＋V → 確認画面が開きます。

※Geminiはアクティビティ（学習）をオフにしてから使ってください。設定方法は「使い方」または「かんたんセットアップ」で案内しています。
BNIコネクトの1to1レポートを取り込む

BNIコネクトからダウンロードした1to1のレポート（「one-to-one-report」という名前のExcelファイル）を選ぶと、これまでBNIコネクトに登録した1to1を、各メンバーの「1to1の記録」にまとめて入れます（「BNIコネクト登録済み」になります）。同じファイルを何度読み込んでも、二重には登録されません。

1to1ミーティングの文字起こしを取り込む
🎙 録音がある場合は、Geminiで文字起こし
  2. Geminiの入力欄に Ctrl＋V →「＋」→「ファイルをアップロード」で録音ファイル（m4a・mp3・wav など）を選んで送信
  3. 返答をコピーして、下の枠に貼り付けて「保存」
    1時間を超える録音は途中で止まることがあります。その場合は、録音を30分ずつなどに分けて送ってください。
文字起こしファイルをドラッグ　またはクリックして選択
.txt .vtt .srt .docx .pdf .csv .json .md（Zoom・Google Meet・Teams・Notion・tl;dv・Otter・スマホアプリ等の書き出し）
📝 文字起こしのテキストがある場合：下の枠に貼り付け →「」→ Geminiに貼り付けて送信 → 返答をコピーして、同じ枠に貼り直して保存（元の文字起こしも一緒に保存されます）
取り込んだ文字起こしは、そのメンバーの「1to1の記録」に保存され、検索の対象になります。記録の「項目をAIで抽出（コピー）」から、Geminiで相手の情報を各項目に反映できます。
録音・文字起こしは、必ず事前に相手の了承を得てください。
Geminiに録音や文字起こしを渡すと、会話の内容がGoogleに送られます。Geminiのアクティビティ（学習）をオフにしてから使ってください。

1to1 Navi の使い方

はじめての方は、まずを行ってください（10分ほど）。データが消えないための設定と、AIの準備を1画面ずつ案内します。

① 最初にやること　② 1to1シートを取り込む　③ 1to1を記録する　④ BNIコネクトに登録する　⑤ 別のパソコンで使う　スマホで見る　⑥ 困ったとき

① 最初にやること（1回だけ）

  1. パソコンの Google Chrome（または Microsoft Edge）で開きます。スマホやSafariでは保存がうまくできません。
  2. Googleドライブ パソコン版を入れて、Googleアカウントでログインします。
  3. 1to1 Naviの保存ファイルをGoogleドライブの「マイドライブ」に作ります。以後、登録や修正をするたびに自動で保存され、クラウドにも自動でバックアップされます。
  4. 1to1シートの読み取りに使うGemini（Googleの無料AI）に、同じGoogleアカウントでログインし、アクティビティ（学習）をオフにします。

この4つは「かんたんセットアップ」で順番に案内します。

② 1to1シートを取り込む

「取り込み」画面で、Googleの無料AI「Gemini」にシートを読み取ってもらいます。最後に確認画面が出るので、内容を見て「登録」を押します。

Webページ（URL）で届いたとき
  1. 「Webページ（URL）」を選び、URLを貼って「ページを開く」を押します。
  2. 開いたページで Ctrl＋A → Ctrl＋C（Macは ⌘）でコピーし、1to1 Naviに戻って枠に Ctrl＋V で貼り付けます。
  3. 「指示文をコピー」→「Geminiを開く」→ 入力欄に Ctrl＋V して送信します（ページの内容も一緒に貼り付けられます）。
  4. 返答の下にあるコピーのアイコン（四角が2つ重なった形）を押し、手順3の枠に貼り付けます。

BNIの名簿（メンバー略歴シート）のページを貼り付けた場合は、「このまま取り込む」ボタンが出ます。Geminiを使わずに、全項目が正確に入ります。

PDF・画像・Word・PowerPointで届いたとき
  1. 「PDF・画像・Word・PowerPoint」を選びます。
  2. 「指示文をコピー」→「Geminiを開く」→ 入力欄に Ctrl＋V します。
  3. 入力欄の左の「＋」→「ファイルをアップロード」でシートのファイルを選び、送信します。
  4. 返答の下にあるコピーのアイコンを押し、手順3の枠に貼り付けます。
BNIコネクトに登録済みの1to1をまとめて取り込む
  1. BNIコネクトから、1to1のレポート（「one-to-one-report」という名前のExcelファイル）をダウンロードします。
  2. 「取り込み」画面の「BNIコネクトの1to1レポートを取り込む」で、そのファイルを選びます。
  3. 件数を確認して「取り込む」を押すと、各メンバーの「1to1の記録」に日付・場所・会話のトピックが入り、「BNIコネクト登録済み」になります。何度読み込んでも二重にはなりません。

③ 1to1を記録する

メンバー一覧の見方
  • 業種でまとめる：カテゴリーから自動で「士業」「美容・健康・医療」などに分けて表示します。グループ名を押すと開閉します。振り分けが違う人は、編集画面の「業種グループ」で変えられます。
  • カード／一覧：「☰ 一覧」にすると1人1行で表示され、人数が多くても見渡せます。
  • 絞り込みボタン：「自分のチャプター」「BNIコネクト未登録」「しばらく会っていない人（最後の1to1から3か月以上）」などを1回押すだけで絞り込めます。
  • ★お気に入り：☆を押すと、その人が常に一番上に表示されます。
  1. メンバー一覧でその人を開き、「＋ 1to1を予定する」で日時を入れると、Googleカレンダーにも登録できます。
  2. 1to1が終わったら、その記録の「議事録・録音を追加」を押し、議事録や文字起こしを貼り付けて保存します。あとから入れる分も同じ記録に追記されます（まだ記録がなければ「＋ 1to1を記録」で作ります）。
  3. 文字起こしのテキストがある場合は、枠に貼り付けて「要約をAIで作る（コピー）」→ Geminiに貼り付けて送信 → 返答を同じ枠に貼り直して保存します（要約・相手の事業・紹介の可能性・次のアクションに整理され、元の文字起こしも一緒に残ります）。
  4. 録音がある場合は、同じ画面の「文字起こし用の指示文をコピー」→「Geminiを開く」→ 貼り付けて録音ファイルを添付して送信 → 返答をコピーして貼り付けます。要約と文字起こしが入ります。
  5. 記録の「項目をAIで抽出（コピー）」→ Geminiに貼り付け → 返答を「AIの返答を項目に反映」に貼ると、話の中で分かった相手の情報が各項目に反映されます。

録音・文字起こしは、必ず相手の了承を得てから行ってください。

④ BNIコネクトに登録する

1to1をした記録には「BNIコネクト未登録」の印が付きます。画面上部のお知らせから、BNIコネクトへの登録に必要な内容を確認し、登録が済んだら「BNIコネクトに登録済みにする」を押してください。区分が「BNI以外」の人は対象外です。

⑤ 別のパソコンで使う・パソコンを買い替えた

  1. 新しいパソコンにも Googleドライブ パソコン版を入れて、同じGoogleアカウントでログインします。
  2. 1to1 Naviを開き、「かんたんセットアップ」の保存ファイルの手順で「作成済みの保存ファイルを開く」を選び、マイドライブの「1to1Navi_データ.json」を選びます。
  3. これで、これまでのデータがそのまま使えます。

スマホで見る（閲覧専用）

  1. 登録・編集はパソコンで行います。スマホは見るだけです。
  2. スマホのブラウザでこのページを開き、「📱 閲覧専用」（または青い帯の「保存ファイルを選んで見る」）を押します。
  3. Googleドライブの「1to1Navi_データ.json」を選びます（Googleドライブアプリ／ファイルアプリから選べます）。
  4. 最初に「このスマホにコピーを保存しますか？」と聞かれます。保存すると、次からは開くだけで表示されます（ファイルを選び直す必要はありません）。
  5. パソコンで更新したあとは、「最新にする」でもう一度ファイルを選ぶと最新になります。

コピーを保存しない場合、ページを閉じるとデータは消えます。保存した場合は「データを消して終了」でいつでも消せます。どちらもスマホの画面ロックをかけ、ファイルは他の人に共有しないでください。

⑥ 困ったとき

  • 画面の上に「自動保存 一時停止中」と出る：ブラウザの安全のための仕組みです。「自動保存を再開」を押し、「許可」を選べば元に戻ります。
  • 画面右上が「⚠ 未バックアップ」になっている：保存ファイルが設定されていません。「保存・バックアップ」から設定してください。
  • Geminiが「読み取れません」と答える：Webページの場合は、ページ全体をコピーできているか（Ctrl＋A を押してから Ctrl＋C）確認してください。ファイルの場合は、PDFで保存し直して添付してみてください。
  • Geminiの返答を貼っても項目に入らない：「指示文をコピー」を押してから貼り付けたか確認し、返答を最初から最後まで全部コピーしてください（返答の下のコピーのアイコンを使うと確実です）。
  • データを消してしまった：保存ファイルがマイドライブにあれば、「作成済みの保存ファイルを開く」で戻せます。Googleドライブのゴミ箱や「版の管理」から、以前の状態に戻せる場合もあります。

保存・バックアップ

　保存先やAIの設定を、1画面ずつの案内でやり直せます。

自動保存（おすすめ）
保存ファイルにはメンバーの個人情報が含まれます。自分専用のフォルダに作り、共有フォルダやグループのドライブには置かないでください。

保存用ファイルを1つ作り、登録・編集するたびに自動で書き込みます。
Googleドライブの「マイドライブ」に作ってください（Googleドライブ パソコン版が必要です）。クラウドにも自動でバックアップされ、パソコンを買い替えても、同じファイルを開けば続きから使えます。

保存先ファイルは未設定です

このブラウザは自動保存に対応していません。Google Chrome か Microsoft Edge で開くと使えます。それまでは下の「書き出し」で定期的に保存してください。

個人情報の取り扱いについて（必ずお読みください）

  • データの保存場所：取り込んだメンバー情報は、お使いのパソコンのこのブラウザの中（と、ご自身で設定した保存ファイル）だけに保存され、外部のサーバーには送信されません。
  • 書き出したファイルを他人に渡さない：「JSON／CSVで書き出し」したファイルや自動保存の保存ファイルには、メンバーの個人情報（家族構成・生年月日など）が含まれます。他の人に渡したり、共有フォルダ・グループのドライブに置いたりしないでください。
  • 録音・文字起こしは相手の了承を得てから：1to1を録音・文字起こしする場合は、必ず事前に相手の了承を得てください。
  • AIを使う場合の設定：AIにシートや会話を渡すと、その内容が外部のAIサービスに送られます。おすすめのGeminiは、左下の「設定とヘルプ」→「アクティビティ」で保存を「オフ」にしてから使ってください（オフでも最長72時間はGoogleに保存されます）。
BNIコネクトへの1to1登録（自動入力ボタン）
手動で書き出し
書き出したJSON・CSVにはメンバーの個人情報が含まれます。他の人に渡したり、共有フォルダに置いたりしないでください。

JSONは別のPC・ブラウザへの移行用、CSVはExcelで開く用です。

JSONを読み込む

書き出したJSONを読み込みます。同じメンバーは新しい方で上書きされ、それ以外は追加されます。

全データ削除

このブラウザに保存したメンバー情報をすべて消去します（自動保存中なら保存ファイルも空になります）。元に戻せません。
