個人情報の取り扱いについて（必ずお読みください）

  • データの保存場所：取り込んだメンバー情報は、お使いのパソコンのこのブラウザの中（と、ご自身で設定した保存ファイル）だけに保存され、外部のサーバーには送信されません。
  • 書き出したファイルを他人に渡さない：「JSON／CSVで書き出し」したファイルや自動保存の保存ファイルには、メンバーの個人情報（家族構成・生年月日など）が含まれます。他の人に渡したり、共有フォルダ・グループのドライブに置いたりしないでください。
  • 録音・文字起こしは相手の了承を得てから：1to1を録音・文字起こしする場合は、必ず事前に相手の了承を得てください。
  • AIを使う場合の設定：「AI用にコピー」でChatGPTやClaudeに貼り付けると、会話の内容が外部のAIサービスに送られます。ChatGPTは「設定 → データコントロール → すべての人のためにモデルを改善する」をオフにしてから使ってください。Claudeなど他のAIも、設定のプライバシー項目で学習への利用をオフにしてください。
このブラウザではデータを保存できない設定になっています（プライベートモード等）。「保存・バックアップ」で保存先ファイルを設定してください。

1to1シートを取り込む

PDF・Word・PowerPointをここにドラッグ＆ドロップ
またはクリックしてファイルを選択（複数まとめてOK）
「メンバー略歴シート／G.A.I.N.S.ワークシート」「Power 1to1 SHEET」のほか、自作の資料も見出しから読み取ります
Webページ（Canvaなど）で届いた場合
  1. 「ページを開く」で別タブにページが開きます
  2. 開いたページで Ctrl＋A（全選択）→ Ctrl＋C（コピー）Macは ⌘
  3. このタブに戻り、下の枠をクリックして Ctrl＋V（貼り付け）→ 自動で読み取ります
※ブラウザの安全上の制限により、URLだけで直接読み込むことはできないため、この手順になります。
1to1ミーティングの文字起こしを取り込む
文字起こしファイルをドラッグ　またはクリックして選択
.txt .vtt .srt .docx .pdf .csv .json .md（Zoom・Google Meet・Teams・Notion・tl;dv・Otter・スマホアプリ等の書き出し）
取り込んだ文字起こしは、そのメンバーの「1to1の記録」に保存され、検索の対象になります。記録の「AI用にコピー」から、ClaudeやChatGPTで要約して各項目に反映できます。
録音・文字起こしは、必ず事前に相手の了承を得てください。
AIに貼り付けると会話の内容が外部サービスに送られます。ChatGPTは「設定 → データコントロール → すべての人のためにモデルを改善する」をオフに、Claudeなど他のAIも設定のプライバシー項目で学習への利用をオフにしてから使ってください。

保存・バックアップ

自動保存（おすすめ）
保存ファイルにはメンバーの個人情報が含まれます。自分専用のフォルダに作り、共有フォルダやグループのドライブには置かないでください。

パソコンの中に保存用ファイルを1つ作り、登録・編集するたびに自動で書き込みます。
OneDrive・Googleドライブ・Dropbox などの同期フォルダに作ると、クラウドにも自動でバックアップされ、別のパソコンでも同じファイルを開けば続きから使えます。

保存先ファイルは未設定です

このブラウザは自動保存に対応していません。Google Chrome か Microsoft Edge で開くと使えます。それまでは下の「書き出し」で定期的に保存してください。

BNIサイトへの1to1登録（自動入力ボタン）
自分のチャプター

BNIサイトに1to1を登録するとき、相手が他チャプターの方なら探し方を案内します。

手動で書き出し
書き出したJSON・CSVにはメンバーの個人情報が含まれます。他の人に渡したり、共有フォルダに置いたりしないでください。

JSONは別のPC・ブラウザへの移行用、CSVはExcelで開く用です。

JSONを読み込む

書き出したJSONを読み込みます。同じメンバーは新しい方で上書きされ、それ以外は追加されます。

全データ削除

このブラウザに保存したメンバー情報をすべて消去します（自動保存中なら保存ファイルも空になります）。元に戻せません。
